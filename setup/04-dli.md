# Method 4 — NVIDIA DLI free courses

Not compute. This buys two things:

1. **A credential line** for each Kaggle notebook header. Readers trust
   content more when the author has done the vendor's own training, and
   trust converts to upvotes.
2. **GUI knowledge you cannot get headless.** Every other method here is
   headless. The DLI labs run the real Isaac Sim interface in your browser on
   NVIDIA-hosted GPUs, which is the only free way to learn the UI.

and which are free changes over time. The first one is reliably free.

## Do this in week 1

It is the lowest-effort item in the whole plan and it unblocks nothing else,
so it is pure parallel work while Isaac Sim installs on Lightning.

Also worth putting on the resume directly — for the robotics-sim roles being
targeted, "NVIDIA DLI: Isaac Sim" is a recognised line.
